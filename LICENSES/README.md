# Lizenzmodell wie in NaC

| Inhalte | Lizenz |
| --- | --- |
| Fachwortschatz und Katalog in `ontology/`, `catalog/` und `cases/`, README, Dokumentation, Textvorlagen in `sources/` und Mermaid-Diagramme | [CC-BY-4.0](CC-BY-4.0.txt) |
| Datenvalidatoren und Generatoren in `scripts/`, `tests/` sowie technische GitHub-Workflows in `.github/workflows/` | [AGPL-3.0-or-later](AGPL-3.0-or-later.txt) |

Diese Zuordnung übernimmt die Trennung zwischen fachlichen Inhalten und ausführbarem Code aus [NaCs Lizenzpolicy](https://github.com/notariat8/NaC/blob/main/policies/license-policy.yaml). Für neue Dateien gilt die Lizenz ihrer Kategorie, sofern sie ausdrücklich keine andere Lizenz nennen. Die Lizenztexte liegen hier vollständig bei. Die Rechte an NaC selbst bleiben bei den dort benannten Rechteinhabern; [NOTICE](../NOTICE) hält die Herkunft fest. Lizenzen gewähren keine Markenrechte.

Editor-Software und Betriebsunterlagen werden seit 2026-10-01 separat in [editor8](https://github.com/ontologie8/editor8) gepflegt. Historische Editorquellen bleiben über die Git-Historie nachvollziehbar.
